# Updates

Updates to this emulator will come on a bi-weekly or monthly basis until it has been completed

### release 0.2.0 will have 

- finished emulator code
- Mac and Linux support
- bug fixes (will be described when released)
- full screen, borderless window and windowed support

### release 0.3.0 will have
- controller support
- key binds support
- some major bug fixes

### release 0.4.0 will have 
- major UI overhaul making it look better than a generic placeholder to add text
- multiplayer support

### release 1.0.0 **final release**
- finishing touches and final improvements
